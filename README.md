## Project Overview
A simple React application for managing a music playlist. Built with Vite, React (JavaScript), and React Router without external UI libraries, Redux, or Context API.

### Key Features
- Client-Side Routing: Home (/), Songs (/songs), Song Details (/songs/:id), and Playlist (/playlist).
- State Management: State maintained in App.jsx and passed via props.
- Live Playlist Count: Navbar displays live count of songs in playlist.
- Duration Formatter: Formats seconds to m:ss.
- Trending Indicator: Displays [Trending] for songs with 1,000,000+ streams.
- Search and Genre Filter: Search by title and filter by genre.
